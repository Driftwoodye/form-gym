# FORM — Your Physique Project

Personal progressive workout tracker and 12-week gym programme. This repository hosts the static progressive web app. No personal workout logs are uploaded; data stays in each user's browser unless exported manually.

Once GitHub Pages is enabled for `main` at `/ (root)`, open https://driftwoodye.github.io/form-gym/ on Chrome for Android and select **Install app** or **Add to Home screen**.
